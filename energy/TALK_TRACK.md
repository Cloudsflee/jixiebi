# 图表答辩话术（可直接使用）

1. `01_时序对比_功率电流累计能耗`  
结论：三面板时序显示优化后功率、电流与累计能耗曲线整体下移；阶段底色区分工况，峰值更少。

2. `02_功率分布箱线图`  
结论：箱线图叠加各 run 均值散点（n 轮重复）；优化后中位与分布整体左移，统计上非单次偶然。

3. `03_功率分布趋势`  
结论：左图 KDE 显示优化后高功率区概率密度降低；右图 ECDF 证实分布向低功率迁移。

4. `04_任务阶段能耗堆叠图`  
结论：100% 堆叠对比各阶段占比，柱顶标注总能耗（Wh）；可定位高耗能阶段贡献。

5. `05_阶段能耗曲线对比`  
结论：各阶段 mean±SEM 曲线显示优化后在关键阶段系统性低于优化前。

6. `06_关节能耗贡献对比`  
结论：J2/J3 为主要耗能关节；优化后高贡献关节降幅更显著，符合动力链优化。

7. `07_单位任务能耗_节能率_降碳率`  
结论：双面板避免双 Y 轴；(a) 单位任务能耗带误差条并标注优化幅度；(b) 节能率与降碳率相对优化前基线。

8. `08_稳定性对比_尖峰与波动率`  
结论：尖峰次数与功率 CV 均带 SEM；优化后双指标下降，控制更平稳。

9. `09_碳排估算对比`  
结论：按电网排放因子估算 gCO₂e/任务，优化后显著降低，与节能率一致。
