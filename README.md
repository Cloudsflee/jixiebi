# 项目上下文（长期约束）

本文档用于记录本项目的稳定硬件前提，避免在后续对话或会话切换后出现理解偏差。

## 已确认的硬件组合

1. 开发板：开源6路舵机控制器
   - 参考文档：`doc/01 开源6路舵机控制器使用说明.pdf`

2. 蓝牙模块：与该控制器配套的蓝牙模块。

3. 舵机类型：**不是**控制器原配舵机。
   - 实际使用舵机为 `doc/03 STM32版本开发教程.pdf` 中描述的总线舵机。
   - 因此相关源码应按“总线舵机方案”进行调整。

4. 最终应用目标：
   - 将“控制器 + 蓝牙 + 总线舵机”组合用于自制3D打印机械臂的动力执行部分。

## 工程实现约束

- 默认优先采用“总线舵机控制链路”进行实现与修改。
- 不默认沿用原配PWM舵机方案作为最终正确方案。

## 开发流程约束（已切换）

- 本项目后续默认且仅使用 `GCC + Makefile` 流程开发与构建。
- 不再保留和维护 Keil/MDK 工程文件。
- 常用命令：
  - 编译：`make -f gcc/Makefile all`
  - 清理：`make -f gcc/Makefile clean`
  - 串口烧录（CH340）：`make -f gcc/Makefile flash FLASH_PORT=COM5 FLASH_BAUD=115200`
