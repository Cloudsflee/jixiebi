# figures 目录说明

本目录包含节能减排展示图，共 9 组图（每组 `PNG + SVG` 两种格式）。  
- `PNG`：适合直接插入 PPT/Word。  
- `SVG`：矢量图，适合论文排版和无损缩放。  

数据对象说明：
- `本机-优化前`：优化前基线。
- `本机-优化后`：目标方案。
- `同类机械臂A/B`：匿名同类机型对照。

## 图表逐项说明

### 01_时序对比_功率电流累计能耗
- 文件：
  - `01_时序对比_功率电流累计能耗.png`
  - `01_时序对比_功率电流累计能耗.svg`
- 内容：同一任务周期内，展示 `功率(W)`、`电流(A)`、`累计能耗(Wh)` 随时间变化。
- 读图要点：
  - 优化后曲线整体更低，峰值更少。
  - 累计能耗曲线斜率更小，说明全流程节能。
- 适用场景：开场“整体效果”页。

### 02_功率分布箱线图
- 文件：
  - `02_功率分布箱线图.png`
  - `02_功率分布箱线图.svg`
- 内容：多轮任务下不同对象的功率分布箱线图。
- 读图要点：
  - 中位数越低，常态功耗越低。
  - 上四分位和离群点越低，说明高功耗风险更低。
- 适用场景：证明“不是单次巧合，而是统计改进”。

### 03_功率分布趋势
- 文件：
  - `03_功率分布趋势.png`
  - `03_功率分布趋势.svg`
- 内容：功率直方分布 + 平滑趋势。
- 读图要点：
  - 优化后高功率区出现频率更低。
  - 分布向低功率区偏移，说明效率改善。
- 适用场景：解释“运行点迁移到高效区”。

### 04_任务阶段能耗堆叠图
- 文件：
  - `04_任务阶段能耗堆叠图.png`
  - `04_任务阶段能耗堆叠图.svg`
- 内容：各任务阶段（待机准备/抓取接近/负载搬运/精准放置/回零复位）的能耗构成。
- 读图要点：
  - 可直观看出高耗能阶段。
  - 优化后主要下降阶段可被定位。
- 适用场景：讲“节能改在哪些工况”。

### 05_阶段能耗曲线对比
- 文件：
  - `05_阶段能耗曲线对比.png`
  - `05_阶段能耗曲线对比.svg`
- 内容：每个阶段的能耗折线对比。
- 读图要点：
  - 若优化后在所有阶段均低于优化前，说明改进是系统性而非局部。
- 适用场景：阶段化论证页。

### 06_关节能耗贡献对比
- 文件：
  - `06_关节能耗贡献对比.png`
  - `06_关节能耗贡献对比.svg`
- 内容：J1~J4 各关节能耗贡献对比。
- 读图要点：
  - 识别主要耗能关节。
  - 验证优化是否命中关键关节（通常 J2/J3）。
- 适用场景：机械结构/控制策略解释页。

### 07_单位任务能耗_节能率_降碳率
- 文件：
  - `07_单位任务能耗_节能率_降碳率.png`
  - `07_单位任务能耗_节能率_降碳率.svg`
- 内容：柱状图展示单位任务能耗，折线图展示节能率和降碳率。
- 读图要点：
  - 体现“节能 -> 减排”的直接关系。
  - 便于给出明确百分比结论。
- 适用场景：比赛核心结论页。

### 08_稳定性对比_尖峰与波动率
- 文件：
  - `08_稳定性对比_尖峰与波动率.png`
  - `08_稳定性对比_尖峰与波动率.svg`
- 内容：峰值尖峰次数 + 功率波动率（CV）双指标对比。
- 读图要点：
  - 尖峰更少表示电气冲击更小。
  - 波动率更低表示控制更稳定。
- 适用场景：可靠性与工程可用性页。

### 09_碳排估算对比
- 文件：
  - `09_碳排估算对比.png`
  - `09_碳排估算对比.svg`
- 内容：不同对象单任务估算碳排（gCO2e）对比。
- 读图要点：
  - 直观展示减排效果，便于与“节能减排”主题对齐。
- 适用场景：结尾总结页。

## 建议展示顺序（答辩）

1. `01`（总览）
2. `02/03`（统计真实性）
3. `04/05/06`（结构与阶段机理）
4. `07/08/09`（结论与价值）
