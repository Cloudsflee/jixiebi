# SuArmT URDF 人工修正清单

本文档用于明确：哪些内容必须由机械/控制同学人工确认后再写入 URDF 或配置文件。

## 1. 关节类型必须人工确认

当前 `SuArmT/urdf/SuArmT.urdf` 中 `01~07` 都是 `revolute`。  
需要逐个确认：

1. 是否为主动关节（可独立控制）。
2. 是否为被动关节（随机构联动，不独立控制）。
3. 是否应改为 `fixed`。

未确认前，不建议把全部关节直接接入控制链路。

## 2. 关节限位必须人工补齐

当前 `01~07` 的 `limit.lower/upper` 全为 `0`，这是导出默认值，不可直接作为真实运动学约束。

需要人工提供每个可动关节的：

1. `lower`（rad）
2. `upper`（rad）
3. 如控制层按角度管理，还需给出对应 `minDeg/maxDeg`

建议来源优先级：

1. 实机机械止挡实测
2. CAD 装配干涉检查
3. 舵机规格与安装偏置换算

## 3. 末端夹爪联动关系需人工定义

`05/06/07` 位于末端分支，是否存在齿轮/镜像/比例联动，需要人工确认。  
若存在联动，应给出：

1. 主驱动关节（driver）
2. 从动关节（follower）
3. 关系式（例如 `theta_follower = a * theta_driver + b`）

可落地为 URDF `mimic`，或前端配置中的 coupling 规则。

## 4. 零位与轴向正方向必须人工标定

URDF 轴向是几何定义，不等于控制“正转”方向。  
需要人工确认每个控制关节：

1. 机械零位定义
2. 正方向（与控制命令正负是否一致）
3. 是否需要 `invert`

否则会出现“角度数值正确但实机方向相反”。

## 5. 控制映射（servoId）必须人工确认

前端/网关控制依赖 `joints.json` 中的 `servoId`。  
URDF 不包含你的真实总线 ID 映射，必须人工维护：

1. 关节名 -> 舵机 ID
2. 安全位（guardMin/guardMax）
3. 默认位（defaultPos）

## 6. 建议的验收顺序（人工+软件联调）

1. 先确认 `01~04` 主运动链可独立正反转。
2. 再确认 `05/06/07` 是否参与控制或只做被动显示。
3. 最后开启联动/约束（如 mimic 或闭链耦合）。

## 7. 本轮改造中的自动化边界

本轮脚本改造将自动完成：

1. 从 `SuArmT` 读取 URDF 和 STL。
2. 生成前端使用的全局 STL 与 `joints.json` 基础结构。
3. 保持当前 4 轴控制框架（`j1~j4`）稳定运行。
4. 对 `SuArmT` 默认启用旧耦合保护：`legacyCouplings.allowForSuArmT=false`。

本轮不会自动猜测：

1. 真实限位
2. 夹爪联动公式
3. 零位与方向标定结果
